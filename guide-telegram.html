📨 ELEVEN TIMER • GUIDE OFFICIEL

Activer les alertes Telegram en 5 minutes

Tutoriel pas à pas — aucune compétence technique requise.
Suivez simplement les étapes dans l'ordre.

A

Installer Telegram (si ce n'est pas déjà fait)

  1. Téléchargez l'application Telegram : sur Play Store (Android) ou App Store (iPhone). Sur ordinateur : rendez-vous sur telegram.org.
  2. Ouvrez Telegram et créez votre compte avec votre numéro de téléphone. Vous recevrez un SMS de confirmation — c'est gratuit et sans abonnement.
B

Créer votre robot (bot)

  1. Dans la barre de recherche en haut de Telegram, tapez exactement : @BotFather
    C'est le robot officiel de Telegram — il possède un badge bleu vérifié ✔️. Ouvrez sa conversation.
  2. Appuyez sur le bouton bleu DÉMARRER en bas de l'écran.
  3. Envoyez-lui la commande : /newbot
  4. BotFather vous demande un nom pour votre bot. Écrivez par exemple : Mon Timer Bot (ce nom est libre, personne ne le voit).
  5. Puis il vous demande un identifiant unique qui doit obligatoirement se terminer par _bot. Par exemple : timer_dental_bot
Ce que vous verrez à l'écran
VOUS/newbot
BotFather ✔️Alright, a new bot. How are we going to call it? Please give me a name for your bot.
VOUSMon Timer Bot
BotFather ✔️Good. Now let's choose a username for your bot. It must end in « bot ».
VOUStimer_dental_bot
BotFather ✔️Done! Congratulations on your new bot. Use this token to access the HTTP API:
7123456789:AAHfLk9xQzW2mNoP4rStUvWyX1234567890
  1. 🎉 Le long numéro coloré ci-dessus est votre TOKEN. Copiez-le entièrement : appui long dessus → Copier. Conservez-le précieusement.
C

Récupérer votre Chat ID

  1. Dans la recherche Telegram, tapez : @userinfobot
  2. Ouvrez la conversation et appuyez sur Démarrer. Il répond immédiatement :
Réponse automatique
@userinfobotId: 771062122
First: Abdeldjalil
Lang: fr
  1. Le numéro après Id: est votre CHAT ID. Notez-le.
D

Activer votre bot ⚠️ étape oubliée n°1 !

  1. Retournez dans la conversation du bot que vous venez de créer (étape B). Cherchez son identifiant, ex : timer_dental_bot, ou cliquez directement sur le lien que BotFather a envoyé (t.me/timer_dental_bot).
  2. Appuyez sur le gros bouton bleu DÉMARRER en bas.
    ⚠️ Obligatoire : tant que vous n'avez pas appuyé sur DÉMARRER, Telegram interdit au bot de vous écrire. C'est la cause n°1 des messages qui n'arrivent pas !
E

Configuration finale dans WordPress

  1. Connectez-vous à votre tableau de bord WordPress, puis ouvrez le menu ⏳ Eleven Timer.
  2. Collez le TOKEN (partie B) dans le champ « Token du bot Telegram ».
  3. Collez votre CHAT ID (partie C) dans le champ « Chat ID Telegram ».
  4. Cliquez sur 💾 ENREGISTRER LES RÉGLAGES.
  5. Cliquez sur 📱 TEST WHATSAPP / TELEGRAM → dans 2 secondes, vous recevez le message de test sur Telegram. ✅ C'est terminé !

🛠 Dépannage — ça ne marche pas ?

  • Aucun message reçu → Vous avez oublié le bouton DÉMARRER (partie D). C'est le cas dans 9 fois sur 10.
  • Erreur « Unauthorized » → Le TOKEN est mal copié (espace en trop ou bout manquant). Recopiez-le depuis BotFather.
  • Erreur « chat not found » → Le CHAT ID est incorrect. Refaites la partie C.
  • Vous avez changé de téléphone ? → Rien à faire, Telegram fonctionne avec votre numéro, pas votre appareil.
🔒 Sécurité : ne partagez jamais votre TOKEN — il donne le contrôle total de votre bot. En cas de doute, demandez-en un nouveau à @BotFather avec /token.

A

Install Telegram (if not already done)

  1. Download the Telegram app from the Play Store (Android) or App Store (iPhone). On computer: go to telegram.org.
  2. Open Telegram and create your account with your phone number. You will receive a confirmation SMS — it is free, no subscription needed.
B

Create your bot

  1. In the search bar at the top of Telegram, type exactly: @BotFather
    This is Telegram's official bot — it has a verified blue badge ✔️. Open the chat.
  2. Tap the blue START button at the bottom of the screen.
  3. Send the command: /newbot
  4. BotFather asks for a name for your bot. Type for example: My Timer Bot (any name works).
  5. Then it asks for a unique username that must end with _bot. For example: timer_dental_bot

Get your Chat ID

  2. Open the chat and tap Start. It replies instantly:

Activate your bot ⚠️ most forgotten step!

  1. Go back to the conversation with the bot you just created (step B). Search for its username, e.g. timer_dental_bot, or click the link BotFather sent (t.me/timer_dental_bot).
  2. Tap the big blue START button at the bottom.
    ⚠️ Mandatory: until you press START, Telegram forbids the bot from messaging you. This is the #1 reason messages never arrive!
E

Final setup in WordPress

  1. Log in to your WordPress dashboard, then open the ⏳ Eleven Timer menu.
  2. Paste the TOKEN (part B) into the “Token du bot Telegram” field.
  3. Paste your CHAT ID (part C) into the “Chat ID Telegram” field.
  4. Click 💾 ENREGISTRER LES RÉGLAGES (Save settings).
  5. Click 📱 TEST WHATSAPP / TELEGRAM → within 2 seconds you receive the test message on Telegram. ✅ Done!

🛠 Troubleshooting — not working?

  • No message received → You skipped the START button (part D). This causes 9 out of 10 issues.
  • “Unauthorized” error → The TOKEN was copied incorrectly (extra space or missing part). Re-copy it from BotFather.
  • “Chat not found” error → The CHAT ID is wrong. Redo part C.
  • Changed phone? → Nothing to do — Telegram works with your number, not your device.
🔒 Security: never share your TOKEN — it gives full control of your bot. If in doubt, ask @BotFather for a new one with /token.
