⚡ OFFERPULSE • v1.0

Plugin OfferPulse — Offres Dynamiques

Icône flottante futuriste pour vos promotions : elle ne gêne jamais le site, se déplace, s'efface au défilement et évite les autres widgets. Popup premium aux couleurs de votre marque.

  • 🛰️  Icône orbite animée — anneau rotatif, halo pulsant, badge du nombre d'offres
  • 🖱️  Déplaçable — le visiteur la glisse où il veut (position mémorisée)
  • 🧠  Anti-collision intelligente — s'empile au-dessus des chats et widgets flottants
  • 👻  S'efface au défilement — revient dès la remontée : zéro gêne de lecture
  • ⏳  Compte à rebours par offre — J-45, J-2 clignotant, 🔥 dernier jour
  • 🏢  Votre marque — nom d'entreprise, sous-titre, couleur d'accent, position L/C/R
  • 🖼️  Bibliothèque médias — offres illimitées avec expiration automatique
  • ♿  Accessible & léger — clavier, ESC, reduced-motion, 100 % vanilla JS

Installation en 3 étapes

  1. Téléchargez le ZIP ci-dessus.
  2. WordPress : Extensions → Ajouter → Téléverser une extension, sélectionnez le ZIP puis activez.
  3. Menu ⚡ Offres … dans l'admin : nom de l'entreprise, position, couleur, puis ajoutez vos offres (image 🖼️ + lien + date d'expiration). C'est tout !
