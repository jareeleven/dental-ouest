🛰️ ELEVEN TIMER • v5.0

Plugin Eleven Timer Futuriste

Surveillance automatique de l'abonnement d'hébergement WordPress : icône discrète « T », accès protégé par mot de passe, compte à rebours futuriste et alertes doublées E-mail + Telegram/WhatsApp. Bilingue automatique FR / EN.

  • ⏳  Compte à rebours temps réel — jours / heures / minutes / secondes
  • 🔒  Accès sécurisé par mot de passe (icône « T » en bas à droite)
  • ✉️📨  Alertes doublées E-mail + Telegram (ou WhatsApp) à J-90, J-30, J-15 et J-7
  • 🚨  Alerte rouge automatique dès l'expiration
  • 🌍  Bilingue automatique FR / EN — s'adapte à la langue du site
  • 🎛️  Panneau d'administration complet avec journal des envois

Installation en 4 étapes

  1. Téléchargez le fichier ZIP ci-dessus.
  2. Dans WordPress : Extensions → Ajouter → Téléverser une extension, puis sélectionnez le ZIP.
  3. Activez : l'assistant de configuration s'ouvre (dates + e-mail + Telegram).
  4. Cliquez sur l'icône « T » en bas du site et saisissez le mot de passe : Eleven1975@

📨 Configurer les alertes Telegram (2 minutes)

  1. Dans Telegram, cherchez @BotFather → envoyez /newbot → choisissez un nom puis un identifiant se terminant par _bot. BotFather vous donne votre token (ex : 7123456789:AAHx…).
  2. Cherchez @userinfobot → il affiche votre Chat Id (ex : 771062122).
  3. Ouvrez la conversation avec votre nouveau bot et appuyez sur Démarrer.
  4. Dans WordPress : menu ⏳ Eleven Timer → collez le token et le Chat Id → Enregistrer → bouton 📱 TEST WHATSAPP / TELEGRAM. C'est tout !
